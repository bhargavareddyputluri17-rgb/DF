# Ex.No.3 – Wireshark

## Password Capturing Using Wireshark

### Aim

To capture and analyze network packets using **Wireshark** and understand how login credentials can be exposed when transmitted through insecure protocols such as HTTP.

---

## Software Required

- Wireshark
- Windows / Linux Virtual Machine
- Web Browser
- Network Connection

---

## Introduction

Wireshark is a network packet analyzer that captures and analyzes network traffic.

It can capture different types of information transmitted over a network, including usernames, email addresses, and other data. In insecure protocols such as **HTTP, FTP, and Telnet**, sensitive information may be transmitted without adequate encryption.

This experiment demonstrates packet filtering and analysis using Wireshark.

---

## Procedure

### Step 1: Start Wireshark

1. Open Wireshark on Windows or a Linux virtual machine.
2. Select the required network interface.
3. Start capturing network packets.

---

### Step 2: Generate Network Traffic

1. Open a website in a web browser.
2. Enter login credentials on the website.
3. Submit the login form while Wireshark is capturing packets.

> **Note:** Perform this experiment only on systems and traffic that you own or have explicit permission to analyze.

---
