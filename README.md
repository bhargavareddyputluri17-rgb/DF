# Digital Forensics

## Ex. No. 5: Use Autopsy to Create a Case and Import Evidence

### Aim

To create a forensic case using **Autopsy** and import digital evidence for forensic analysis.

---

## Description

**Autopsy** is an open-source digital forensics platform used for analyzing and extracting data from digital devices.

In this experiment, Autopsy is used to:

- Create a new forensic case
- Import digital evidence
- Configure ingest modules
- Analyze forensic artifacts
- Perform keyword and file analysis
- Perform timeline and hash analysis
- Generate forensic reports

---

## Software Required

- **Autopsy**
- Windows / Linux / macOS
- Digital forensic evidence image
